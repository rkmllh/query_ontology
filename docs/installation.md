# Installation

## Stable release

To install Brain Tumor Detection, run this command in your terminal:

```sh
uv add brain_tumor_detection
```

Or if you prefer to use `pip`:

```sh
pip install brain_tumor_detection
```

## From source

The source files for Brain Tumor Detection can be downloaded from the [Github repo](https://github.com/rkmllh/brain_tumor_detection).

You can either clone the public repository:

```sh
git clone https://github.com/rkmllh/brain_tumor_detection
```

Or download the [tarball](https://github.com/rkmllh/brain_tumor_detection/tarball/main):

```sh
curl -OJL https://github.com/rkmllh/brain_tumor_detection/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd brain_tumor_detection
uv sync
```
